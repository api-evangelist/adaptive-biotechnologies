# Adaptive Biotechnologies

> Adaptive Biotechnologies Corporation (Nasdaq: ADPT) is a Seattle, Washington immune-medicine
> company that sequences and interprets the adaptive immune system. Its clonoSEQ assay is an
> FDA-cleared next-generation sequencing test for measurable residual disease (MRD) in blood
> cancers; its immunoSEQ assays, immunoSEQ Analyzer and immuneACCESS repository serve research;
> and its MRD biopharma services support drug development. Adaptive sells laboratory tests and
> services, not software. As of 2026-09-07 it publishes no developer portal, no public API
> reference, no SDK and no machine-readable specification of any kind.

## API surface

- [No public API](https://www.adaptivebiotech.com/): probed 2026-09-07 — /openapi.json,
  /openapi.yaml, /swagger.json, /api-docs, /v1/openapi.json, /llms.txt, /apis.json and the full
  named /.well-known set return HTTP 404 on www.adaptivebiotech.com, adaptivebiotech.com,
  clients.adaptivebiotech.com and www.clonoseq.com. No GraphQL, no MCP server, no A2A agent
  card, no AsyncAPI, no gRPC and no WSDL was found.
- [clonoSEQ EMR integration](https://www.clonoseq.com/emr-integration/): the real integration
  surface. clonoSEQ orders and results move through Epic (including Epic Aura), Flatiron
  Health's OncoEMR via Molecular Profiling Integration, and Carequality / health information
  exchanges. Access is arranged with Adaptive's integration specialists at
  emrsupport@adaptivebiotech.com; an Epic build is described as an 8–12 week project. No
  interface specification is published.
- [immunoSEQ Analyzer](https://clients.adaptivebiotech.com/login): cloud analysis application
  for immunoSEQ data, behind a customer login. No API is documented for it.
- [immuneACCESS](https://clients.adaptivebiotech.com/immuneaccess): public immune-repertoire
  data repository. Access is open but registration-gated, via download in the web application;
  no programmatic interface is published.
